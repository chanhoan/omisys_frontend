Typography

Hangul carries the interface; Latin carries the attitude. Pretendard is the workhorse — the de-facto modern Korean UI face, flawless for prices, sizes, body copy and 한글. On top of it sit two display voices that switch per direction.

02

Color

Strictly monochrome. Three near-neutral grounds — true paper, warm stone, and ink — so a direction can read crisp-white, soft-warm, or blacked-out without ever introducing a hue. Photography is the only place color is allowed to live.

Scope & plan

  • 01Home / storefront — hero drop, editorial rows, new-in rail, collections.
  • 02Category list (PLP) — filter + sort sheet, grid / single-column toggle.
  • 03Product detail (PDP) — gallery, size picker, fit notes, add-to-bag.
  • 04Search & discovery — recent, trending, live results.
  • 05Bag → checkout — address, shipping, pay, confirmation.
  • 06Wishlist + Account / orders.

Deliverables: this brief · a clickable iOS prototype with the 3 directions + tweaks · a Claude Code handoff doc for the React Native build.
